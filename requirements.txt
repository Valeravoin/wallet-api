# --- Основные зависимости для работы приложения ---

fastapi==0.109.0
    # Фреймворк для создания API. Даёт роуты, валидацию запросов (Pydantic), автоматическую документацию (Swagger UI).

uvicorn[standard]==0.27.0
    # Асинхронный ASGI-сервер. Запускает FastAPI-приложение. Опция [standard] добавляет зависимости для лучшей производительности (uvloop, ujson).

sqlalchemy==2.0.25
    # ORM и SQL-инструменты. В твоём проекте используется в асинхронном режиме (sqlalchemy.ext.asyncio) для работы с базой данных.

asyncpg==0.29.0
    # Драйвер для PostgreSQL, оптимизированный под asyncio. Используется основным приложением (app) для асинхронного доступа к БД (вместо psycopg2).

# --- Миграции и управление схемой БД ---

alembic==1.13.1
    # Инструмент миграций БД. Позволяет версионировать схему (создавать/менять таблицы) и применять изменения через команды вроде `upgrade head`.

psycopg2-binary==2.9.9
    # Синхронный драйвер PostgreSQL. Нужен Alembic для применения миграций (Alembic по умолчанию синхронный). Не используется основным приложением.
    # Важно: именно наличие этого пакета позволяет команде миграции работать корректно, иначе будет ModuleNotFoundError.

# --- Тестирование ---

pytest==8.3.2
    # Основной фреймворк для написания и запуска тестов. В проекте покрывает логику кошельков и конкурентные сценарии.

pytest-asyncio>=0.23.0
    # Плагин для pytest, позволяющий писать и запускать асинхронные тесты (async def). Критично для твоих тестов с httpx и asyncpg.

httpx==0.26.0
    # HTTP-клиент с поддержкой async/await. Используется в тестах для отправки реальных HTTP-запросов к запущенному FastAPI-приложению.

# --- Утилиты и разработка ---

python-dotenv==1.0.1
    # Загружает переменные окружения из файла .env. Позволяет хранить DATABASE_URL и другие секреты локально, не хардкодя их в коде.

flake8
    # Линтер для проверки стиля кода и поиска ошибок (неправильные отступы, неиспользуемые импорты и т.д.). Помогает держать код чистым.

black
    # Автоформатер кода. Приводит стиль кода к единому стандарту (PEP 8) без участия человека. Запускается как отдельная команда.
